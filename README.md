# Lucky 21 Description

The player starts with 100 chips and plays against the dealer. The goal is to
get as close to 21 points as possible with the player's cards without exceeding 21.

A round should follow this process:

```text
========================================
           BLACKJACK CONSOLE
========================================

Welcome to Blackjack!

Your balance: 100 chips
Enter bet: 20

----------------------------------------
Dealer:
[ ?? ] [  K  ]

Your cards:
[  8  ] [  7  ]        Score: 15
----------------------------------------

What would you like to do?

1. Draw a card
2. Stand
3. End game

Choice:
```

### How to run
Open the project in IntelliJ or another IDE and run `src/Main.java`.

Instructions for interacting with the application are available in [manual.md](manual.md).
